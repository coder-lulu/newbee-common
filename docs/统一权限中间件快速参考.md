# 统一权限中间件快速参考

## 🚀 5分钟快速集成

### 1. 配置文件 (your-service.yaml)
```yaml
Middleware:
  auth:
    enabled: true
    accessSecret: "your-32-char-secret-key"
    accessExpire: 86400
  tenantCheck:
    enabled: true
  dataPerm:
    enabled: true
    casbinEnabled: true
    coreRpcEndpoint: "127.0.0.1:9101"

RedisConf:
  Host: 127.0.0.1:6379
```

### 2. ServiceContext集成
```go
import "github.com/coder-lulu/newbee-common/middleware/integration"

func NewServiceContext(c config.Config) *ServiceContext {
    result, err := integration.Setup(&integration.Config{
        Redis:                  redis.NewUniversalClient(...),
        JWTSecret:             c.Middleware.Auth.AccessSecret,
        Mode:                  integration.Production,
        Middleware:            &c.Middleware,
        DataPermCasbinProvider: createCasbinProvider(c),
    })
    
    return &ServiceContext{
        ContextManager:    result.ContextManager,
        IntegrationResult: result,
    }
}
```

### 3. 服务器启动
```go
integration.ApplyToServer(server, svcCtx.IntegrationResult)
```

## 📋 权限配置速查

### Casbin规则格式
```sql
-- 策略: p, 主体, 资源, 操作, 域
INSERT INTO casbin_rules (ptype, v0, v1, v2, v3) VALUES
('p', 'admin', '*', '*', '*'),                    -- 超级管理员
('p', 'manager', 'user', 'read', 'tenant1'),      -- 部门经理
('p', 'user', 'profile', 'update', 'tenant1');    -- 普通用户

-- 角色: g, 用户, 角色, 域  
INSERT INTO casbin_rules (ptype, v0, v1, v2) VALUES
('g', 'user_123', 'admin', 'tenant1');
```

### 资源命名规范
```
格式: [service:]resource[:sub_resource]
示例: user, department, cmdb:server, ops:proxy
```

### 操作类型
```
create, read, update, delete, list, export, import, approve, execute
```

## 🎛️ 数据权限级别

| 级别 | 描述 | 生成SQL示例 |
|------|------|-------------|
| `all` | 全部数据 | 无额外条件 |
| `own_dept` | 本部门 | `department_id = 'user_dept'` |
| `own_dept_and_sub` | 本部门+子部门 | `department_id IN (SELECT ...)` |
| `self` | 仅个人 | `user_id = 'current_user'` |

## 🔒 字段掩码类型

| 类型 | 效果 | 示例 |
|------|------|------|
| `none` | 不掩码 | `13812345678` |
| `partial` | 部分掩码 | `138****5678` |
| `full` | 完全隐藏 | `***` |
| `hash` | 哈希显示 | `[HASH:a1b2c3]` |
| `encrypt` | 加密显示 | `[ENCRYPTED]` |

## 💡 常用代码片段

### 检查权限
```go
// 检查是否有特定权限
hasPermission := l.svcCtx.ContextManager.HasPermissionFor(l.ctx, "user", "delete")

// 检查字段访问权限
canAccess := l.svcCtx.ContextManager.IsFieldAccessible(l.ctx, "salary")

// 获取权限上下文
permCtx := l.svcCtx.ContextManager.GetPermissionContext(l.ctx)
```

### 获取用户信息
```go
userID := l.svcCtx.ContextManager.GetUserID(l.ctx)
tenantID := l.svcCtx.ContextManager.GetTenantID(l.ctx)
deptID := l.svcCtx.ContextManager.GetDeptID(l.ctx)
```

### 系统操作
```go
// 创建系统上下文（跳过权限检查）
systemCtx := hooks.NewSystemContext(l.ctx)
err := l.svcCtx.DB.SystemConfig.Create().SetKey("key").Exec(systemCtx)
```

## ⚠️ 注意事项

### 安全要求
- ✅ JWT密钥至少32位
- ✅ 启用strictMode
- ✅ 配置skipTables排除系统表
- ✅ 定期审计权限配置

### 性能优化
- ✅ 启用Redis缓存
- ✅ 合理设置缓存过期时间
- ✅ 避免循环中的权限检查
- ✅ 使用批量操作

### 常见错误
- ❌ 忘记注入CasbinProvider
- ❌ 权限规则配置错误
- ❌ Redis连接失败
- ❌ Core RPC服务不可达

## 🆘 快速故障排查

### 权限检查失败
1. 检查Casbin规则是否正确
2. 验证用户角色关系
3. 确认Core RPC服务状态
4. 启用详细日志

### 字段掩码不生效
1. 检查字段名是否匹配
2. 验证用户角色权限
3. 确认拦截器已注册
4. 查看权限上下文

### 性能问题
1. 检查缓存命中率
2. 优化权限规则复杂度
3. 调整超时设置
4. 使用批量检查
